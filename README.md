# Medication Tracker (Moxie)

Offline-capable iPhone web app for tracking daily scheduled medications, Medrol dose pack progression, and as-needed (PRN) doses.

## Live Web App (iPhone / Safari)

- **URL:** [https://keithowns.github.io/medtracker/](https://keithowns.github.io/medtracker/)

### Installing on an iPhone

1. Open **[https://keithowns.github.io/medtracker/](https://keithowns.github.io/medtracker/)** in **Safari** (or scan `Medication Tracker QR Code.png` with the iPhone camera).
2. Tap the **Share** button (`↑`) at the bottom of Safari and tap **Add to Home Screen** (or tap **Install Home Screen Icon** in the top banner to use `Install Med Tracker Home Screen Icon.mobileconfig`).
3. Launch **Med Tracker** from the iPhone Home Screen. Once opened once, it caches all assets for full offline use and persists checked doses in `localStorage`.
